## Maintaining these docs

The Help Center and the main developer documents have matching pages in `docs/` and `docs/en/`. Update both languages together. Architecture audits and regression records retain their original language. User-facing how-to content lives only in the Help Center; engineering pages keep implementation contracts and link to them. Past changes are in [CHANGELOG.md](https://github.com/redtidev1918/DAViewer/blob/main/CHANGELOG.md) and [RELEASE_NOTES.md](https://github.com/redtidev1918/DAViewer/blob/main/RELEASE_NOTES.md).

The download pages are generated by `.github/scripts/update_download_page.py`. Edit that script to change page wording; the English preview snippet is in `download-preview.md`.
