# Getting started

**Language / 语言:** [中文](/help/getting-started.md) · English

## 1. Install

Pick your platform (Android / Windows / macOS) on the [Download page](/en/download.md) and follow the steps there:

- **Android**: download the APK and install it (you may need to allow "install unknown apps" first).
- **Windows**: unzip the archive and run `daviewer.exe`. Keep the other extracted files next to the exe — don't copy the exe alone.
- **macOS**: unzip and open `DAViewer.app`. The app is unsigned; on first launch right-click it in Finder and choose "Open".

## 2. Sign in to DeviantArt

Tap **Login** in the top-right corner of the home screen.

- DAViewer opens the official DeviantArt sign-in page inside the app. Sign in, register, or use any provider the page offers (Google, Apple, …).
- If the page shows a CAPTCHA, complete it as normal — the app waits for you.
- After signing in you'll see "Syncing sign-in state…" briefly, then your personalized feed appears.

> Why sign in? "Daily Deviations" works without an account, but recommendations, watching, favourites, and notifications need your DeviantArt account. See [Login and account](login-and-account.md).

## 3. Meet the home screen

The home screen has two tabs:

- **For You**: DeviantArt's personalized feed — requires sign-in.
- **Daily Deviations**: official daily picks, no sign-in needed.

Everyday gestures:

- **Pull down** to refresh the list.
- **Scroll down** to load more automatically.
- **Long-press a card** for a shortcut menu: hide this artwork, hide this artist, favourite, share, copy link, open in browser.

## 4. Bottom navigation

| Tab | What it's for |
| --- | --- |
| Home | For You + Daily Deviations |
| Watched | New works from artists you watch |
| Search | Search artworks, users, or #tags |
| Favourites | Everything you've favourited |
| Downloads | Download manager (progress, pause, open files) |

For more, see [Browsing and searching](browse-and-search.md) and [Downloading artworks](download-artwork.md).
