# 网络与代理

**语言 / Language:** 中文 · [English](/en/help/network.md)

## 代理在哪里设置？

打开 **设置 → 网络代理**。只有一个输入框：**HTTP 代理地址**。

## 地址怎么填？

格式是 `主机:端口`，例如：

```
127.0.0.1:7890
http://127.0.0.1:7890
```

要点：

- **端口不是固定的**：填你的代理软件里显示的 **HTTP 或 Mixed 端口**（Clash 等工具通常在主界面或设置里能看到）。
- **`127.0.0.1` 的意思是「代理跑在这台设备上」**：手机上代理 App 和 DAViewer 装在同一台手机时用 `127.0.0.1`；电脑上同理。想让手机用电脑上的代理时，填电脑的局域网 IP（如 `192.168.x.x`），并在代理软件里打开「允许局域网连接」。
- 只支持 **HTTP 代理**（大多数代理软件的 HTTP/Mixed 端口都适用），不支持 SOCKS，也不支持带用户名密码的地址。

## 三个按钮怎么用？

- **保存并测试**：保存地址并立即测试能否连上 DeviantArt，推荐用这个。
- **测试 DeviantArt 连接**：只测当前设置，不改任何东西。
- **恢复自动检测**：清掉手动代理，回到自动检测（应用会尝试系统代理和环境变量；清掉后会立即重新探测）。

测试成功会显示「连接成功」，之后应用内的接口、图片、下载和登录页都走这条网络路径。测试只覆盖应用自己的流量，**不影响**你用浏览器上网。

## 启动时的提示是什么意思？

打开应用时可能会短暂显示「正在检测 DeviantArt 连接…」，然后给出结果：

- 提示可直连或已通过代理 → 一切正常，无需处理。
- 提示无法连接 → 按上文设置代理，或检查网络；详细信息可在 **设置 → 日志与诊断** 里查看。

## 登录页打不开 / 白屏 / 卡住？

1. 确认代理软件已启动、端口填对，点「测试 DeviantArt 连接」看看结果。
2. 页面白屏或加载卡住：点登录页**右上角的刷新**再试。
3. 提示「正在被 DeviantArt 拦截（Max challenge attempts exceeded）」：说明网络触发了官网的风控，**等 1-2 分钟，只刷新一次**，不要连续刷。
4. macOS 12/13 有个特殊情况：应用内测试可能通过，但登录页仍需要**系统代理**（系统设置 → 网络 → 代理）才能加载。

## 报告网络问题

**设置 → 日志与诊断** 可以查看运行日志；点右上角导出按钮可把最近 20 次启动的日志（已脱敏）导出为一个文件，配合「报告问题」按钮可以快速向开发者反馈。
