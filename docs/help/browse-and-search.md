# 浏览与搜索

**语言 / Language:** 中文 · [English](/en/help/browse-and-search.md)

## 搜索

点底部导航的 **搜索** 标签。

- 输入关键词搜索**作品**或**用户**：输入后用搜索框下方的「作品 / 用户」开关切换类型。
- 搜**标签**：输入 `#标签名`（例如 `#digitalpainting`）后按回车，进入标签浏览页；标签页支持按「默认 / 最新 / 热门」排序，底部还有「相关标签」可以继续跳转。
- 作品搜索结果可按「默认 / 最新」排序（右上角「排序」）。
- 没有关键词时会显示「搜索记录」（可单条删除或全部清除）、「为你推荐」和「热门标签」。

## 长按作品卡片：快捷菜单

在任意作品列表里**长按一张卡片**，弹出菜单：

- **屏蔽这幅作品** / **屏蔽这位画师的作品**：从列表里隐藏，随时在 [内容屏蔽](/content-filtering.md) 设置里解除。
- **查看详情**：打开作品页。
- **收藏 / 取消收藏**。
- **分享**、**复制链接**、**在浏览器打开**。

## 收藏

- 作品页里点 **收藏**（爱心按钮）；列表卡片上也有快速收藏按钮。
- 已收藏的内容在底部导航 **收藏** 标签里查看。
- 收藏需要登录，因为它保存在你的 DeviantArt 账号里。

## 浏览历史

看过的作品会自动记录。入口：**设置 → 浏览历史**，右上角「清除」可一次清空。历史只保存在本机。

## 打开链接

朋友分享给你一个 DeviantArt 作品链接？在首页点左上角的链接图标 **打开链接**，粘贴链接（如 `https://www.deviantart.com/xxx/art/xxx-123456789`）即可在应用内打开。

## 通知

首页右上角铃铛是 **通知**（收藏、评论等 DeviantArt 站内消息），进去后可点「全部已读」。
