# 下载与保存

**语言 / Language:** 中文 · [English](/en/help/download-artwork.md)

## 怎么下载？

打开作品详情页，找到下载区域，看「原图：」后面的状态：

| 状态 | 含义 | 你能做什么 |
| --- | --- | --- |
| 可下载 | 可以下载原图 | 点 **下载原图** |
| 需要登录 | 网站登录状态失效 | 到[登录与账号](login-and-account.md)重新登录后再试 |
| 需要购买 | 这是付费作品 | 到 DeviantArt 官网购买后才能下载 |
| 受限 | 账号权限不够（如成人内容设置） | 见[常见问题](faq.md)中的成人内容条目 |
| 不可下载 | 画师关闭了下载 | 用下面的「保存当前画质」 |
| 已删除或不存在 | 作品已下架 | 无法下载 |

- **原图不可下载**时，应用会提示「原图不可下载，但可以保存当前展示的最高画质图片」，按提示保存即可。
- 下载中可以 **暂停 / 继续 / 取消**。
- **多图作品**（卡片带「多图」标记）：下载原图会自动排队下载全部页面。
- 状态看起来不对时，点「重新检查下载权限」再试一次。

## 下载管理

底部导航的 **下载** 标签管理所有下载任务：

- 每个任务显示文件名、状态（已完成 / 下载中 / 已暂停 / 失败 / 源文件失效 / 已取消 / 排队中）和进度。
- 点 **打开** 用应用内看图器查看；电脑版还有 **打开文件夹** 直接定位文件。
- 右上角 **删除已结束下载**：清理已完成的记录及其本地文件（会先弹确认）。

## 文件保存在哪里？

下载完成后，文件会移动到**系统的公共「下载」文件夹**——就是你在文件管理器/访达里看到的那个 Downloads 目录。

- Android 上如果显示「已保存在应用内」，说明系统未授权公共目录，文件在应用私有目录内，可通过系统的「文件」应用或连接电脑访问。
- 失败或暂停的任务会保留在应用内，恢复后继续。

## 下载失败怎么办？

1. 看[网络与代理](network.md)确认连接正常。
2. 「源文件失效」多为作品被修改或下架，回到作品页重新进入再试。
3. 反复失败：**设置 → 日志与诊断** 导出日志并报告问题。
