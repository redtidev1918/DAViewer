# 快速上手

**语言 / Language:** 中文 · [English](/en/help/getting-started.md)

## 1. 安装

到 [下载页面](/download.md) 选择你的平台（Android / Windows / macOS）并按页面步骤安装：

- **Android**：下载 APK 安装包并安装（首次可能需要在系统里允许「安装未知来源应用」）。
- **Windows**：解压压缩包后运行 `daviewer.exe`，请保留解压出来的其他文件，不要只复制 exe。
- **macOS**：解压后打开 `DAViewer.app`。应用未签名，首次打开请在 Finder 里右键点它，选「打开」。

## 2. 登录 DeviantArt 账号

打开 DAViewer 后，点右上角的 **登录** 按钮。

- 应用会在内置页面中打开 DeviantArt 官方登录页，直接用它登录或注册即可，也可以用 Google、Apple 等官方页面提供的登录方式。
- 如果页面出现人机验证（验证码），按页面提示完成即可，应用会等你。
- 登录成功后会显示「正在同步登录状态…」，稍等片刻回到首页就能看到为你推荐的作品。

> 为什么要登录？不登录也能看「每日精选」，但「推荐」、关注、收藏和通知都需要你的 DeviantArt 账号。详见[登录与账号](login-and-account.md)。

## 3. 认识首页

首页有两个标签页：

- **推荐**：DeviantArt 根据你的兴趣生成的个性化首页，需要登录。
- **每日精选**：官方每天挑选的作品，不登录也能看。

常用手势：

- **下拉**刷新当前列表。
- **往下滚动**到底部自动加载更多。
- **长按作品卡片**弹出快捷菜单：屏蔽这幅作品、屏蔽这位画师、收藏、分享、复制链接、在浏览器打开。

## 4. 底部导航

| 标签 | 用途 |
| --- | --- |
| 推荐 | 个性化推荐 + 每日精选 |
| 关注动态 | 你关注的画师的新作品 |
| 搜索 | 搜索作品、用户或 #标签 |
| 收藏 | 你收藏过的作品 |
| 下载 | 下载管理（进度、暂停、打开文件） |

更多玩法见[浏览与搜索](browse-and-search.md)和[下载与保存](download-artwork.md)。
