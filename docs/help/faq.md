# 常见问题

**语言 / Language:** 中文 · [English](/en/help/faq.md)

## 登录页打不开或一直卡住

关掉登录页重新打开；仍不行就到 **设置 → 网络代理** 检查代理并点「测试 DeviantArt 连接」。详见[网络与代理](network.md)。

## 官方页面要求验证码或账号确认

这是 DeviantArt 官方的安全验证，按页面提示完成即可，应用会等你完成，不会中断登录。

## 提示「推荐需要恢复」，但「每日精选」能看

推荐依赖网站登录状态，每日精选不需要。按提示重新登录即可恢复推荐，详见[登录与账号](login-and-account.md)。

## 成人内容被隐藏或显示模糊

DAViewer 直接使用你 DeviantArt 账号的内容偏好，不在应用内单独放行。到 **设置 → DeviantArt 账号设置 → 成人内容设置** 打开官网对应页面，确认账号已开启「显示成人内容」且年龄验证通过，回应用刷新即可。

## macOS 提示钥匙串（Keychain）权限

点「允许」即可——DAViewer 用系统钥匙串保存登录凭证。如果每次都问，可在弹窗里选择「始终允许」。这是 macOS 的正常安全机制，不是故障。

## 想换一个账号

**先退出登录，再登录新账号**（设置 → 退出登录）。不要用 Cookie 导入的方式切换账号，它只接受当前账号的 Cookie。

## 怎么更新应用？

- 有新版本时首页会出现「发现新版本」横幅，点「查看更新」看更新说明，再点「去下载」前往发布页。
- 也可以手动检查：**设置 → 检查更新**。
- 旧版本（Android 0.5.10 及更早）请在发布页手动下载新版安装包覆盖安装。

## 图片加载慢 / 一直转圈

1. 看[网络与代理](network.md)，必要时配置代理。
2. 下拉刷新当前列表。
3. **设置 → 清除缓存** 后重进页面（会重新下载缩略图，不影响登录和收藏）。

## 屏蔽错了想恢复

设置 → **内容屏蔽**，在对应列表里点「解除屏蔽」即可，作品会立刻回到列表里，无需重新下载。详见[内容屏蔽](/content-filtering.md)。

## 还是不行？

**设置 → 日志与诊断**：查看日志、导出最近 20 次启动记录（自动脱敏），或点「报告问题」直接跳转 GitHub 反馈页。
