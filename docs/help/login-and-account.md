# 登录与账号

**语言 / Language:** 中文 · [English](/en/help/login-and-account.md)

## 怎么登录？

点应用右上角的 **登录** 按钮（未登录时才会显示），在内置打开的 DeviantArt 官方页面里完成登录。

- 一切登录、注册、找回密码和第三方登录（Google、Apple 等）都在这个官方页面完成，DAViewer 不单独做「社交登录」。
- 出现人机验证（验证码）时按页面提示完成，应用会一直等你。
- 登录一次会同时完成两件事：账号授权，以及 DAViewer 内部的网站登录状态。之后「推荐」、关注、收藏和通知都可以用。

## 登录成功后，推荐页面为什么还是空白？

DAViewer 的「推荐」需要一份有效的网站登录状态。有时应用显示已登录，但推荐所需的登录信息已经过期。按下面顺序尝试：

1. 在推荐页**下拉刷新**一次。
2. 检查网络连接，确认手机/电脑能正常打开 [deviantart.com](https://www.deviantart.com)；需要代理时见[网络与代理](network.md)。
3. 打开 **设置 → 登录状态**，分别点「推荐与内容浏览」和「关注、收藏与通知」两张卡片里的检查按钮，按提示处理。
4. 仍不行就重新登录一次：设置 → **退出登录**，再点 **登录**。

> 放心：重新登录**不会**删除你在 DeviantArt 上的收藏和关注，它们都保存在你的账号里。设备上已下载的图片也不受影响。

## 「登录失效」提示是什么意思？

DAViewer 可能弹两种提示，处理方式不同：

- **网页登录已失效，推荐等网页功能暂时受限** → 点提示上的 **重新登录**，或到设置里重新登录。
- **App 授权登录已失效** → 点 **重新授权**，重新走一遍登录。

两种都不影响你已收藏、已下载的内容。

## 退出登录 / 更换账号

- 退出：**设置 → 退出登录**（会一并退出应用内的网站登录状态）。
- 更换账号：**先退出登录，再登录新账号**。Cookie 导入不允许混用两个账号。

## 查看、导出与导入 Cookie

Cookie 是什么？可以理解为「网站的登录凭证」，DAViewer 用它来代表你访问 DeviantArt 网页功能。入口在 **设置 → 账号 Cookie**：

- **查看/复制**：页面会显示当前 Cookie（JSON 格式），点「复制 Cookie（JSON）」复制到剪贴板，可保存备用。
- **导入**：点「导入 Cookie」，支持三种格式——应用导出的 JSON、浏览器扩展导出的 Cookie 数组、`name=value; name=value` 形式的请求头文本。
- 导入的 Cookie 必须属于**当前登录的同一个账号**，匿名或账号不匹配都会被拒绝；导入成功后应用可能请求一次免密确认，可以直接关掉。

## 成人内容设置

DAViewer 不单独控制成人内容，直接使用你 DeviantArt 账号的偏好：**设置 → DeviantArt 账号设置 → 成人内容设置**（会打开 DeviantArt 官网对应页面）。在官网上调整后，回到应用刷新即可生效。
