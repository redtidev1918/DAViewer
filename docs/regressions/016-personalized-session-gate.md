# REG-016 未确认会话仍放行个性化推荐

用户报告推荐页显示每日精选内容，而 Cookie 已不能取得个性化推荐，App 没有提示登录。

此前首页只检查本地登录标记，并拦截已确认的 `anonymous`。`unknown`、`unverified`
和 `unavailable` 仍能请求 rfy；该接口即使对匿名 Cookie 返回通用作品，也可能是
HTTP 200。周期复核改善了发现时机，却没有补上请求前的放行条件。

现在推荐请求先复用或取得五分钟内的服务端登录确认。确认匿名时给出登录入口；验证
被网络或挑战阻碍时阻止请求并显示“无法确认网页会话”，不把它误报为 Cookie 到期。
新鲜确认期间，刷新和分页仍不重复验证。请求完成时再次检查会话和账号，避免在途
通用结果在会话失效后进入缓存。

`home_refresh_no_probe_test.dart` 覆盖本地仍声明登录但服务端和真实浏览器返回匿名时
零次 rfy 请求，以及浏览器挑战时零次 rfy 请求且不判定登出。原有刷新、分页和 403
退避测试继续使用真实登录确认，并验证探针不会逐页重复。

测试响应由夹具构造，没有读取用户的 Cookie。首页登录确认并不证明推荐算法必然
个性化；作品与每日精选相似也不证明登出。用户当前会话的具体结论仍需诊断日志或
真实接口证据确认，不能仅凭内容题材推断。
