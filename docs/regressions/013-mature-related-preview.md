# REG-013 更多推荐中的成年作品误显示付费锁和模糊图

## 用户报告

从作品详情的更多推荐打开成年作品，卡片带锁，预览与详情均模糊；从作者页打开同一作品却能看到清晰图片。用户同时报告 Cookie 失效时缺少提醒。

示例：[Candace Cox Gets Plastered and Then Way Too Hungry](https://www.deviantart.com/theraveolution/art/Candace-Cox-Gets-Plastered-and-Then-Way-Too-Hungry-1376809028)。参考实现：[DeviantDrop](https://github.com/redtidev1918/DeviantDrop)。本次未使用用户登录凭据验证该作品的实时响应。

## 已确认的代码路径

更多推荐优先使用网站列表数据，作者页使用官方 OAuth 数据。数字 ID 的详情直接读取列表缓存，不再查询完整媒体；缓存合并还会保留旧访问限制。因此网站的临时模糊媒体或付费标记能一直延续到详情页。

网页会话此前只在启动时校验，提醒条也只挂在主页面。重新登录只刷新个性化信息流，无法主动重试详情页中已经失败的媒体请求。

## 修复

- 对模糊预览或成年作品的付费标记，通过官方接口获取同一作品的详情。匹配作者和作品路径后，用明确返回的媒体与限制更新缓存。
- 保留已核实的媒体，防止点击卡片时再次写入原列表而恢复旧锁和模糊图。真正付费、请求失败或作品不匹配时保持访问限制。
- 可疑媒体触发网页会话复核，合并并发校验并限制触发频率。服务端确认匿名后，在详情页显示重新登录入口；网络或验证页面不等于 Cookie 失效。
- 登录成功后重试详情与网页媒体数据，并作废旧访问解析标记。已失效的在途解析不能写回缓存。
- 保留 `blockReasons` 等原始原因和证据来源，拆分内容限制、媒体状态与解析阶段。NSFW 登录限制和付费限制可以并存；未识别的原因码保持未知。官方主图可访问不代表网页附加图片也可访问。
- 官方接口无法查询时，允许完整网页详情回退；两种来源均不足时提供重试。卡片从更新后的缓存同步读取图片和状态。状态转换与来源规则见 [作品访问状态](../architecture/artwork-access.md)。

## 验证与范围

`artwork_media_hydration_test.dart` 覆盖推荐到详情的完整缓存路径、保留付费锁、请求失败和错误作品、每批最多三个并发请求，以及登录后重试。`web_session_status_test.dart` 覆盖健康缓存中的过期检测、触发节流和验证页面；`artwork_detail_navigation_test.dart` 验证详情页提醒可打开登录入口。

`artwork_access_state_test.dart` 另外覆盖组合限制、未知原因、两种网站页面格式和主图／附加图片权限边界。全量 337 个测试通过。真实账号下该示例的多图内容与服务端访问标记仍需设备验证；自动化测试使用构造响应，不代表已经复现该链接的实时数据。
