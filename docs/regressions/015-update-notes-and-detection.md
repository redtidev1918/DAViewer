# REG-015 更新说明缺失与自动提醒消失

用户报告发布后检查更新没有说明，App 也没有提醒。

v0.5.9 的正式 Release 包含说明和各平台安装包。代码检查发现四处缺口：

- `appVersion` 使用 Dart 环境变量 `FLUTTER_BUILD_NAME`，发布脚本只设置安装包版本，
  没有传入同名 Dart define。默认值 `development` 使自动检查无法比较版本。
- API 不可用时，说明回退读取 `main/RELEASE_NOTES.md`，该文件只维护到 0.5.3。
- 自动检查保存时间戳，却不保存发现的版本；短时间重启后，空状态被时间戳抑制。
- 手动检查失败时显示“已是最新版本”，把网络失败当成成功结果。

发布脚本现在给 Android、Windows、macOS 构建显式传入 Dart 版本变量。说明优先
读取 Release 正文，其次读取对应标签下 `.github/release-notes/<version>.md`，最后
回退到旧聚合文件。旧聚合文件补入 0.5.9 说明，供旧客户端使用。

自动检查的成功缓存只在当前进程保留，重启重新检查；五分钟内复用当前结果，失败不
删除已发现的提醒。检查由 App 启动、前台恢复和前台五分钟定时器驱动，后台暂停。
提醒继续显示在首页，并尊重用户对同一版本的关闭操作。手动检查即使已是最新版本
也显示该版本说明，获取失败则显示检查失败。

自动化测试覆盖说明回退、重启、并发合并、失败保留和跨重启关闭记录。构建脚本测试
要求每个平台都显式传入 Dart 版本变量。真实安装包内版本和前后台时序仍需实机验证。
已发布的 v0.5.9 二进制不会因源码修复而改变，客户端改动需安装后续修复版。
